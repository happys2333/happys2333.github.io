开源实践

Deskflow：客户端可靠性

围绕 C++ / Qt 客户端的事件生命周期，修复断连清理时机：保持分发中的处理器有效，在回调返回后执行清理，并结合回归测试与 AddressSanitizer 验证。

已合并贡献：#9958。这里的贡献者身份不代表项目维护者身份。

CC Switch：配置与会话状态一致性

为 Codex 服务商切换开发跨会话状态协调、凭据隔离与失败回滚相关修复；另提交 OMO Slim 活跃预设导入修复，在处理预设时保留自定义配置字段。

对应已提交 PR：服务商切换 #5815、预设导入 #7228。是否合并及后续进展以仓库记录为准。

Gitea：界面与后端规则一致

修正关闭 PR 后的分支删除按钮。当分支仍被其他开放 PR 使用时，不再展示后端无法完成的删除操作。

已合并贡献：#39193。

这些实践共同训练的是定位问题、理解已有约束、控制修改范围与补充验证的能力，而不只是新增代码。

两个代表项目

AI Ladder

项目仓库

使用 Vue 3 / Vite 构建 AI 模型榜单与编程套餐浏览界面，通过 Python 等脚本整理多源数据，支持模型检索、排序、最多三个模型并排比较与双语浏览。重点是数据口径、标准化与交互表达，而不是简单堆叠一张排行榜。

DataMiningFinal

项目仓库

基于 Python / PyTorch 的数据挖掘课程实验，围绕四座城市的病例序列完成数据准备、滑动窗口构造、ConvTrans / LSTM / 回归模型对比和可视化。样本有限，定位为学习与探索项目，不包装成经过验证的生产级预测系统。
